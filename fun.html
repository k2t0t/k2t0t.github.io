install VMWare

1. go to https://www.vmware.com/products/workstation-player/workstation-player-evaluation.html

2. click download now

3. create account or login to broadcom

4. click "My Downloads" tab on the left

5. click "Free software downloads available here" in blue

6. scroll down and click Workstation Pro

7. download latest version for your os, follow installation instructions

8. if it doesn't end up working just use 17.0

installing and using images

1. install VMWare

2. download the image

3. extract the image, enter password if needed

4. inside of the extracted file, select the file w/ the 3 box icon (.vmx) and run it in VMware

4. when prompted, select "I copied it"

5. enjoy

how to create clean image

1. install VMware

2. download an iso of the version u want, easily available with a google search

3. on VMware, create a new virtual machine, typical configuration, and select the iso

4. follow steps and remember to allocate reasonable amount of ram, disk space, and cpu cores

5. start VM and install the os

6. snapshot while it's clean so you can always revert to a clean state (tutorial below)

7. u can use this image to check default files and do other testing
