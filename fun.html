install VMWare

1. go to https://www.vmware.com/products/workstation-player/workstation-player-evaluation.html

2. click download now

3. login or create account to broadcom

4. click "my downloads" tab on the left

5. click "free software downloads available here"

6. scroll down and click VMware Workstation Pro

7. download latest version for your os, follow installation instructions

8. if it doesn't end up working just use 17.0

installing and using images

1. install VMWare

2. download the image

3. extract the image, enter password if needed

4. inside of the extracted file, select the file w/ the 3 box icon and run it in VMware

4. when prompted, selected "i copied it"

5. enjoy

how to create clean image

1. install VMware

2. download an iso of the version u want

3. create a new virtual machine and select the iso

4. allocate reasonable amount of ram, disk space, and cpu cores

5. hop on the image and install the os

6. if you need defaults for a specific service u can just download it

7. u can run this image to check default files and do other testing
